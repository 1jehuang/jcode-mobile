## Reproduced defects and changes

- `593b3da`: closing and reopening a local chat discarded unresolved-delivery protection. Unresolved submissions, pending commands, and uncertain outcomes now retain their tab-independent state. Poll epochs prevent stale closed-tab polling. Five closure outcomes and loopback HTTP outage, pagination recovery, and transcript replacement have regression coverage.
- `1fc3e8c`: the actual clipboard paste handler replaced multiline code line breaks with spaces. Multiline editors now preserve exact pasted text. Single-line fields normalize CRLF, CR, and LF without leaving carriage returns. Real clipboard tests include Unicode and selected-range replacement.
- `1fc3e8c`: manual editor line geometry stayed at 20 pixels when larger text required 32 pixels. Layout, caret, range, and pointer geometry now use the same scaled line height. A drawn scale-1.6 regression failed before the fix.
- `f6d4525`: a long draft at 320 by 568 with larger text overlapped the software keyboard by 57 points. Visible composer rows now use the available viewport budget, retaining the complete draft while scrolling its caret. The drawn regression covers three viewport sizes in both connected and disconnected states.
- `a1670fe`: account replacement and signout retained parked conversations, drafts, auto-send state, and session-map data. Shared workspace disposal now clears account-owned state. Socket events are fenced to their connection epoch.
- `cc1420d`: stale Live Activity refresh results could be applied to another authenticated workspace. Completion checks now include account identity and authentication generation.
- `b0f8af3`: stale cloud device-login callbacks could affect a later account. Login start, poll, cancel, and completion paths now reject stale authentication generations.
- `f365d80`: synced list refresh, transfer acknowledgement, and transfer polling accepted callbacks from an earlier login when the same account was subsequently installed again. Authentication epochs now fence refresh, enqueue completion, prefetch, postfetch, and timeout handling, with active poll identity checked as well. Three focused ABA regressions failed before the fix and pass afterward.
- `2142e7a`: visual followthrough found the local routing footer still clipped behind a compact keyboard. Compact waiting/routing text and a larger-text-aware chrome budget keep it visible. Visible row limits are separate from multiline semantics, so a one-visible-row composer still preserves pasted code line breaks. The actual drawn local-footer test failed before this fix and passes afterward.
